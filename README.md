# Simple Counter Application

A clean, modern, and responsive Counter Application built using vanilla JavaScript, HTML5, and CSS3. This project features dynamic UI updates, smooth button transitions, and a minimalist card design.

---

## Features

- **Dynamic Counter:** Increase, decrease, or reset the counter value instantly.
- **Smooth Animations:** Interactive button effects (`hover` and `active` scale states).
- **Responsive Layout:** Perfectly centered modern card layout using CSS Flexbox.
- **Clean Codebase:** Well-structured and commented code, making it easy to understand and extend.

---

## Preview

[Live Demo]()

- **Increase:** Adds `1` to the current value.
- **Decrease:** Subtracts `1` from the current value.
- **Reset:** Resets the counter value back to `0`.

---

## File Structure

```text
├── index.html       # The HTML structure of the application
├── style.css        # Custom modern styling and transitions
└── script.js        # Core JavaScript logic managing the counter state
```

## How to Run

1. Clone or download this repository to your local machine.

2. Open the index.html file directly in any modern web browser (Chrome, Edge, Safari, Firefox).

3. Start interacting with the counter!

## Technologies Used

- HTML5: Semantic markup structure.

- CSS3: Custom linear gradients, box-shadows, flexbox positioning, and transitions.

- JavaScript (ES6): DOM manipulation and event handling.
